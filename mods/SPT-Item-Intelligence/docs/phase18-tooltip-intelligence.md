# Phase 18 — tooltip intelligence

Phase 18 turns the deeper marker tooltip modes into actionable item intelligence while leaving the approved compact modes and marker semantics unchanged.

## Presentation contract

- Minimal remains `Value` plus `Keep ×N`;
- Normal remains the aggregate `Quest Now`, `Quest Later`, `Hideout` and `Keep ×N` view;
- Detailed adds the winning market source/unit price, ₽/slot, Owned and up to three named requirement targets;
- Full exposes every named target before the low-priority decision and template id;
- named quest targets retain FIR status;
- hideout targets include the area name and required level;
- `SAFE TO SELL` remains Full-only and never becomes central;
- source/value never affect marker color.

## Data and performance contract

- the server resolves the trader name with the same SPT 4.1.2 first-loyalty buy-price coefficients used by `TraderHelper.GetHighestSellToTraderPrice`;
- completed quest conditions are removed before requirement projection;
- requirement detail objects are immutable snapshot data carried through the existing atomic indexes;
- tooltip strings are generated by the existing cache and never rebuilt per repaint;
- no polling, hierarchy scans or per-item GameObjects are introduced.
