Target: SPT 4.1.3.

The current HeadBand is a `1x2` utility container with an exact currency/cigarette/wallet whitelist. The current mechanical Belt candidate is `2x2` magazine-only; ArmBand remains `1x2` magazine-only.

Do not use the user as a per-patch debugger. This gate is valid only after the same exact head has passed the hot-path guard, deterministic regressions, offline profile recovery, client build, server build and install-tree packaging.

## Performance boundary

The client must remain interaction/event driven. GridWindow correction performs at most eight bounded settle passes per relevant opened window. Scav compatibility resolves property/field runtime shape once and then uses cached delegates over only the three wearable slots. There must be no permanent `Update` polling, scene-wide inventory scan, per-`ReplaceInventory` reflection scan, or global UI mutation loop.

## Decision rule

A runtime PASS requires the complete product-critical matrix above to show no profile/lifecycle/death/insurance defect. Cosmetic presentation defects may be separated only when they are demonstrably non-destructive and do not obscure slot/container use. On FAIL, return only the smallest evidence requested by the failed row; remediation resumes from that concrete boundary.

Profile recovery is packaged under `SPT_Runtime/user/mods/B&A&HB #2 MOD SPT/profile-safety/`.
