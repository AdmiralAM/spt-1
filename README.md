# SPT Pause runtime

Ready-to-install standalone **SPT Pause v0.1.1** for SPT **4.1.x**.

Copy this branch into the SPT root. Press P in an offline raid to pause/resume. Phase 1 freezes world ticks and Unity time, preserves the raid/display timers and time of day through reflected clock anchors, shows PAUSED on the raid timer, excludes hideout/network sessions and restores state on scene changes. Physical in-game validation is still pending. This channel contains Pause only.
