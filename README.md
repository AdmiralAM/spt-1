# Item Valuation MOD SPT runtime

Ready-to-install standalone **Item Valuation MOD SPT v1.0.0** for **SPT 4.1.3**.

Copy this branch into the SPT root. The package is server-only and installs under `SPT_Runtime/user/mods/Item Valuation MOD SPT/`; it does not install a BepInEx plugin.

This runtime channel contains only Item Valuation MOD SPT. It preserves the accepted 1.0.0 behavior: economic-value background tiers for normal items, total-value tiers for weapons/armor, original key-specific valuation coloring, and penetration-based ammunition tiers.
