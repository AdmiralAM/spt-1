# B&A&HB #2 MOD SPT — Stable v0.1.0

**Status:** STABLE / physically accepted on SPT 4.1.3.

This branch is the ready-to-install publication channel. It is not a development branch.

## Install

1. Download this branch as ZIP.
2. Open the archive and open the `SPT_Runtime` folder inside it.
3. Copy the contents of that folder into your existing `C:\Games\SPT\SPT_Runtime\` directory and allow file replacement.
4. Remove/disable legacy `Trenchfoot-BeltSlot.dll` if it is still installed.
5. Start SPT normally.

## Included

- client: `SPT_Runtime/BepInEx/plugins/SPT Belt Armband Inventory v0.1.0.dll`
- server: `SPT_Runtime/user/mods/B&A&HB #2 MOD SPT/SPT-Belt-Armband-Inventory.Server.dll`
- profile-safety recovery material and persistent-ID manifest

## Stable contract

This is the first accepted stable B&A&HB baseline: ArmBand container support, dedicated Belt slot 15, dedicated HeadBand slot 16, first-open Items stability, PMC lifecycle persistence and configurable exact-root death/insurance protection.

Further product/UI development is intentionally excluded from this stable channel.
